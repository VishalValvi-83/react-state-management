# State Management - Zustand Counter

A simple React application to demonstrate state management with Zustand.

## Technologies Used

- [React](https://reactjs.org/)
- [Zustand](https://github.com/pmndrs/zustand)
- [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/)

## What is Zustand?

-_“Zustand is a lightweight React state management library that lets you create global stores easily. It removes the complexity of Redux and Context API by providing a simple hook-based API. It’s great for medium to large apps where multiple components need to share state efficiently.”_
